# Implicit vs. Explicit CSS Grid

In CSS Grid layout, understanding the difference between the **Explicit Grid** and the **Implicit Grid** is key to managing both static structures and dynamic, unpredictable content.

---

## 📐 1. Explicit Grid

The **Explicit Grid** consists of the rows and columns intentionally defined by the developer using structural properties:
* `grid-template-columns`
* `grid-template-rows`

### Characteristics
* **Predictable Structure**: You explicitly declare track sizes and counts upfront.
* **Control**: Gives precise control over layout dimensions.

---

## 🔄 2. Implicit Grid

The **Implicit Grid** refers to tracks (rows or columns) automatically generated by the browser when grid items overflow or are placed outside the explicit grid boundaries.

Control over implicit track sizing is handled by:
* `grid-auto-rows`
* `grid-auto-columns`

### Example Scenario

If you explicitly define **only 2 columns**, but supply **6 grid items**, the browser automatically creates **3 implicit rows** to fit all items.

#### HTML
```html
<link rel="stylesheet" href="styles.css">
<div class="grid-container">
  <div class="grid-item">Item 1</div>
  <div class="grid-item">Item 2</div>
  <div class="grid-item">Item 3</div>
  <div class="grid-item">Item 4</div>
  <div class="grid-item">Item 5</div>
  <div class="grid-item">Item 6</div>
</div>
```

#### CSS
```css
.grid-container {
  display: grid;
  /* Explicitly defining 2 columns */
  grid-template-columns: 100px 100px;
  
  /* Optional: Set height of automatically created implicit rows */
  grid-auto-rows: minmax(80px, auto);
}

.grid-item {
  background-color: burlywood;
  border: 1px solid orangered;
  padding: 0.5rem;
  margin: 0.5rem;
}
```

---

## 📊 Summary Comparison: Explicit vs. Implicit Grid

| Feature | Explicit Grid | Implicit Grid |
| :--- | :--- | :--- |
| **Size Control** | Fully customized via `grid-template-rows` and `grid-template-columns`. | Controlled by `grid-auto-rows` and `grid-auto-columns` (defaults to `auto`). |
| **Default Behavior** | Remains fixed unless explicitly redefined. | Automatically expands when content exceeds explicit limits. |
| **Complexity** | Requires planning grid structure ahead of time. | Handles unstructured or dynamic content automatically. |
| **Flexibility** | Rigid, predefined layout structure. | Flexible and adaptable to dynamic items. |
| **Performance** | Highly performant due to predefined structural parameters. | Requires real-time browser calculations for new tracks. |
| **Primary Use Case** | Predictable macro layouts (headers, sidebars, cards). | Dynamic feeds, user-generated content, lists of varying length. |

---

## 🧠 Quick Review (TL;DR)

* **Explicit Grid**: Defined intentionally via `grid-template-*` properties.
* **Implicit Grid**: Created automatically by the browser to fit extra content.
* **Sizing Implicit Tracks**: Use `grid-auto-rows` or `grid-auto-columns` to control automatic track sizing instead of letting them default to `auto`.
