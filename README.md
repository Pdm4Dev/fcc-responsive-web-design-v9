This repository contains my hands-on practice, workshops, labs, and certification projects completed as part of the updated **Responsive Web Design v9** curriculum on [freeCodeCamp](https://www.freecodecamp.org/).

The main goal of this repository is to build a solid foundation in modern web development, practice building real components locally, document key takeaways, and assemble a clean project portfolio.
